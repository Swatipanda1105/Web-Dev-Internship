#JavaaScript Day 11 Practice

##Overview
This project covers the basics of JavaScript, including linking an external `.js` file to HTML and printing formatted outputs using `console.log()`.

##How to Run
1.Download or clone this repository to your computer.
2.Open the `Day11_JavaScript_Introduction` folder.
3.Double-click `index.html` to open it in anyweb browser(Chrome,Edge,Firefox,etc.).
4.Right-click on the webpage and select  **Inspect**(or press 'F12'). 
5.Click on the **Console** tab to view printed Javascript outputs and the About Me card.
