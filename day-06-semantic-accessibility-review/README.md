# Day 06 — Semantic HTML & Accessibility Review

## Overview
This project audits and refactors my earlier HTML profile and contact form pages to meet semantic HTML5 structure and WCAG accessibility best practices.

## Key Improvements
- Replaced non-semantic `<div>` containers with `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
- Enforced sequential heading levels (`<h1>` and `<h2>`).
- Added descriptive `alt` text and meaningful link labels.
- Associated all form inputs with explicit `<label>` elements and tested full keyboard-only (`Tab` / `Shift+Tab`) navigation.
- Documented all findings in `accessibility-audit.md`.
